# Git & GitHub Workshop — Starter Portfolio

This is a small static website for practising Git, GitHub repositories, commits, pushing, and GitHub Pages deployment.

## Files
- `index.html` — page content
- `style.css` — layout and visual design
- `README.md` — project notes

## Workshop tasks
1. Replace `Your Name` with your name in `index.html`.
2. Update the introduction and add one skill.
3. Update the GitHub and LinkedIn links to your own public profiles.
4. Commit your changes with a clear message.
5. Push the repository to GitHub.
6. Enable GitHub Pages from **Settings → Pages**:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
7. Open the Pages URL shown in Settings → Pages.

## Important
- This project is plain HTML and CSS. No Node.js, build command, or package installation is required.
- The website may take a few minutes to appear after enabling Pages or pushing changes.
- Do not publish passwords, private contact details, API keys, or other sensitive information.
- Google Fonts is an optional external dependency; the site still has fallback fonts if it cannot load.
